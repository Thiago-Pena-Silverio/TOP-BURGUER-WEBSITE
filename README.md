# Top Burguer

Top Burguer is a three-page website for a fictional burger restaurant. I built it as the final assessment for a web development module. The pages are written in Portuguese and share a CSS stylesheet.

## Explore the site

- **[Home](pages/index.html)** gives an overview of the restaurant and links to its menu and reviews.
- **[Menu](pages/menu.html)** lists each burger with its ingredients, including a vegetarian option.
- **[Reviews](pages/reviews.html)** displays sample customer ratings.

## Run locally

1. Choose **Code → Download ZIP** on this repository and extract the archive.
2. Open `pages/index.html` in a web browser. Keep the other pages, stylesheet and images together in the extracted folder.

The site uses HTML and CSS and runs directly in a browser.
